# Personal News — browser web service

Полноценное веб-приложение: React-интерфейс в браузере, FastAPI backend, SQLite, запуск через Docker Compose.

## Что умеет
- Добавлять RSS/Atom-источники и сразу загружать публикации
- Хранить источники и новости в SQLite
- Обновлять все источники одной кнопкой
- Фильтровать публикации по периоду
- Просматривать заголовки, описания, даты и оригинальные ссылки
- Удалять источники

## Запуск

Нужен установленный Docker Desktop (Windows/macOS) или Docker Engine + Compose (Linux).

1. Распакуйте архив.
2. Откройте терминал в папке `personal_news_web`.
3. Выполните:

   ```bash
   docker compose up --build
   ```

4. Откройте в браузере:

   **http://localhost:8080**

API доступно по адресу `http://localhost:8000/docs`.

Остановка: `Ctrl+C`, затем `docker compose down`.
Данные SQLite сохраняются в Docker volume `news_data`, поэтому не пропадают при обычном перезапуске контейнеров.

## Размещение в интернете

Этот проект можно развернуть на VPS с Docker:
- установить Docker и Compose;
- скопировать папку проекта на сервер;
- запустить `docker compose up -d --build`;
- настроить домен и HTTPS через Caddy или Nginx Proxy Manager.

Важно: в текущей версии нет авторизации. Не выставляйте приложение в публичный интернет без защиты (например, Basic Auth/VPN) и не используйте его для хранения приватных данных. Для публичного доступа нужно добавить аутентификацию, ограничить CORS, защитить API и настроить HTTPS.

## Примечания
- Некоторые RSS-ленты могут быть недоступны из-за ограничений сайтов.
- RSS часто содержит только анонс, а не полный текст публикации.
- Это первая итерация: без AI-дайджеста, расписания и аудио.
